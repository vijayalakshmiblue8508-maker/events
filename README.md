**JavaScript Events Demo**

This project demonstrates different types of JavaScript Events using simple HTML, CSS, and JavaScript.

It helps beginners understand how events work in web development.

**Features**

**This demo includes:**

Click Event
Double Click Event
Mouse Over & Mouse Out Events
Key Press Event
Focus Event
Change Event

**Technologies Used**

HTML5
CSS3
JavaScript (Vanilla JS)

**Project Structure**

events.html

The complete project is written inside a single HTML file.

**Event Demonstrations**

**1. Click Event**

<button onclick="clickEvent()">

When the button is clicked, a message is displayed.

**Output:**

Button Clicked!

**2. Double Click Event**

<button ondblclick="doubleClickEvent()">

Triggers when the button is double-clicked.

**Output:**

Button Double Clicked!

**3. Mouse Over & Mouse Out Events**

onmouseover="mouseOverEvent()"
onmouseout="mouseOutEvent()"
Changes box color when mouse enters
Restores color when mouse leaves

**Effects:**

Orange → Red
Text changes dynamically

**4. Key Press Event**

onkeypress="keyPressEvent(event)"

Displays the key pressed by the user.

**Example Output:**

Key Pressed : A

**5. Focus Event**

onfocus="focusEvent()"

**When the input field is focused:**

Background changes to light yellow
Output message appears

**Output:**

Input Focused
**6. Change Event**

<select onchange="changeEvent(this.value)">

Displays the selected food item from dropdown.

**Example Output:**

Selected Food : Pizza
